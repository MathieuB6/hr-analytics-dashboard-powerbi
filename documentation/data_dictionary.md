# Dictionnaire de données

| Colonne | Description |
|---|---|
| Age | Âge du salarié |
| Attrition | Indique si le salarié a quitté l’entreprise |
| BusinessTravel | Fréquence des déplacements professionnels |
| Department | Département du salarié |
| EducationField | Domaine d’études |
| Gender | Genre du salarié |
| JobRole | Poste occupé |
| JobSatisfaction | Niveau de satisfaction au travail |
| MonthlyIncome | Salaire mensuel |
| OverTime | Indique si le salarié effectue des heures supplémentaires |
| TotalWorkingYears | Nombre total d’années d’expérience |
| YearsAtCompany | Ancienneté dans l’entreprise |
| YearsInCurrentRole | Ancienneté dans le poste actuel |
| YearsSinceLastPromotion | Nombre d’années depuis la dernière promotion |
| YearsWithCurrManager | Nombre d’années avec le manager actuel |

## Colonnes calculées principales

| Colonne | Description |
|---|---|
| C_Departement | Département traduit en français |
| C_Genre | Genre traduit en français |
| C_Poste | Poste traduit en français |
| C_Statut | Statut du salarié : Présent ou Parti |
| C_Tranche_Age | Tranche d’âge |
| C_Anciennete | Tranche d’ancienneté |
| C_Satisfaction | Niveau de satisfaction traduit en français |
| C_Heures_Supplementaires | Indique si le salarié fait des heures supplémentaires |
| C_Risk Score | Score de risque construit à partir de plusieurs facteurs RH |
| C_Risk Level | Niveau de risque : Faible, Modéré ou Élevé |

## Note

Le jeu de données est utilisé dans un cadre portfolio pour démontrer la création d’un dashboard Power BI RH.
